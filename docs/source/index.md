# Airborne Gravity Quality Control

__galileoQC__[^PrimeRef] is a Python package for quality assurance and control of airborne gravity[^GravNote] data. It covers both gravimetry and gradiometry from a range of instrument types and was designed for use in QC of data collected under contracts based on the Airborne Gravimetry and Gravity Gradiometry Technical Standards [^GravDeed]. It has also proved useful in the QC of many other airborne gravity surveys. Some functions are provided for the QC of aeromagnetic data.
